# For Khuthi — interactive proposal

A mobile-first, cinematic, single-page proposal site made with plain HTML, CSS, and JavaScript.

## Preview locally
Open `index.html` in a browser. The optional ambient soundtrack is generated in the browser and begins only after the visitor taps **Sound off** (browser autoplay rules).

## Publish at your existing GitHub Pages site
1. Download and unzip this folder.
2. In your `Ngelekanyo/Khuthi` repository, create a folder named `proposal`.
3. Upload `index.html`, `style.css`, and `script.js` into that folder.
4. Commit the changes to `main`.
5. If GitHub Pages already publishes the repository root, the page should be available at `https://ngelekanyo.github.io/Khuthi/proposal/` after the deployment finishes.

You can also open the repository's **Settings → Pages** to verify the current publishing source. GitHub Pages publishes static files; the site entry file must be in the folder being served.

## Personalise before sending
- Edit the message in `index.html` so it sounds unmistakably like you.
- The current soundtrack is a soft synthesized ambient pad, not a commercial song. If you'd rather use a specific song, add an audio file you have permission to use and wire it to the sound button.
- The page is public once deployed. Avoid putting private details in the repository.
